# Một Kiếp Việt

**Một đời người, vạn ngã rẽ.** Game mô phỏng cuộc đời bằng tiếng Việt, chạy hoàn toàn trong trình duyệt.

Yêu cầu Node.js 24+.

```powershell
npm.cmd ci
npm.cmd run dev
```

Mở địa chỉ cục bộ được in ra (mặc định http://127.0.0.1:5173). Không có dịch vụ trả phí hoặc backend.

```powershell
npm.cmd run verify
npm.cmd run simulate
npm.cmd run test:e2e
```

Thiết kế: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Bản MVP đang được xây dựng và kiểm chứng; báo cáo bàn giao ghi bằng chứng sau khi hoàn tất.
